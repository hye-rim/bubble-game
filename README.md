# 퍼즐 버블 🫧

같은 색 구슬 3개 이상을 붙여 터뜨리고, 매달린 구슬은 한꺼번에 떨어뜨리는 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

## 조작
- PC: 마우스로 조준하고 클릭 발사(또는 `←` `→` 조준, `Space` 발사). `↓` 또는 NEXT 구슬을 눌러 구슬 바꾸기.
- 폰: 끌어서 조준하고 손을 떼면 발사.

## 규칙
- 같은 색이 3개 이상 붙으면 터지고, 이어진 곳이 끊긴 구슬은 같이 떨어집니다.
- 구슬이 아래까지 내려오면 끝. 최고 점수는 `bubbleBest`.

## 🎁 아이템 모드 (시작 화면에서 고름)
기본 규칙은 그대로이고, 일정 발사 수마다 **특수 구슬**이 NEXT 로 나옵니다. 기록은 **기본 모드와 따로** 저장됩니다(`bubbleItemBest`). 기본 모드 기록(`bubbleBest`)은 로비에 보이는 그대로입니다.
- 💣 **폭탄**: 붙은 자리를 둘러싼 구슬(바로 이웃한 6칸)을 터뜨립니다. 판에 남지 않습니다.
- 🌈 **무지개**: 이웃한 색 중 놓았을 때 **가장 큰 덩어리가 되는 색**으로 바뀌어 붙습니다. 3개 이상이면 터지고, 아니면 그 색 구슬로 남습니다.
- ⚡ **번개**: 붙은 줄을 통째로 지웁니다(그 줄이 비어 있으면 바로 위 줄).
- 터뜨린 뒤 천장에서 끊긴 구슬이 떨어지는 **낙하 보너스는 그대로** 적용되고, 구슬 하나당 10점입니다.
- 특수 구슬은 **7~11번 쏠 때마다 한 번**(폭탄 35%·무지개 40%·번개 25%). NEXT 와 바꾸기(`↓`)로 아껴 둘 수도 있습니다.

### 균형을 어떻게 맞췄나
- 각도를 미리 시험해 가장 많이 터뜨리는 쪽을 쏘는 봇(일부러 엉뚱하게 쏘는 비율 25%·50%)을 14판씩 돌렸습니다. 기본 모드 스테이지 중앙값 10·점수 73,640 → 아이템 모드 스테이지 11·점수 145,300(엉뚱히 쏨 50%에서는 7 → 7, 36,770 → 66,730). **모든 판이 끝나므로 판이 영영 안 끝나지는 않고**, 스테이지는 비슷하고 점수는 약 2배입니다(번개·폭탄이 낙하 보너스를 크게 만들기 때문). 기록이 따로라 그대로 뒀습니다.
- **사람이 하는 체감 재미·난이도와 폰 터치 감각은 측정하지 못했습니다.**

## 구조
- `game.js` 화면·입력·소리, `logic.js` 규칙(구슬 배치·터짐·낙하).
- 규칙은 DOM 없는 `logic.js`(특수 구슬 `stick`·`clearCells`·`rainbowColor`·`pickNext` 포함), 시험은 `node --test` (`test/logic.test.js`, 아이템 시험 10개 포함).
